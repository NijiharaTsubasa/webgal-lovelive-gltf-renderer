# 离屏角色准备

`OffscreenCharacter.create(options)` 返回独立的离屏角色。`options.motion` 和 `options.expression` 指定初始动作与表情，省略或空字符串使用角色默认值。创建过程在播放时间零完成状态求值、物理初始收敛、参数动作绘制资源建立、Shader 编译和实际离屏绘制。宿主接入 Pixi 时还需完成所属渲染上下文的画布纹理上传。

`setPreloadRequests(options[])` 接受按使用先后排列的完整前瞻需求，每次调用替换当前需求。宿主根据有限的剧情前瞻窗口提交需求，缓存容量随需求数量调整，准备任务串行执行。`preloadId` 标识一次预计出现；同一模型预计同时出现两份时，提供两个不同的 ID。已取用的 ID 在同一需求中保持已消费状态，后续出现使用新的 ID。

当前前瞻需求持有已准备实例。移出前瞻的闲置实例保留最多 60 秒，并在容量不足时优先释放；需求减少时立即释放超出容量的闲置实例。取消后尚未完成的创建仍占用准备通道，完成后释放。失败的需求可通过下一次显式提交重试。离开场景时提交空列表，解除当前前瞻需求，闲置缓存继续受最近一次需求容量与过期时间约束。

`takePreloaded(options)` 按模型、清单、画布尺寸、构图及初始动作表情取用一个实例，调用时立即转移该实例的所有权。相同状态的多份需求对应独立角色；取用后由宿主负责更新与销毁。未找到可用实例时返回 `null`，宿主可调用 `create` 按需创建。`preload(options)` 用于单独准备一个候选，替换此前未使用的候选，准备完成后保留最多 60 秒。

每个离屏角色拥有独立的 WebGL 上下文，宿主需要控制同时显示与预热的总规模。准备过程中丢失上下文会报错；取用时发现上下文已丢失的缓存会被释放，并返回 `null` 供宿主重新创建。

返回的角色已处于所请求的初始状态，接入时直接开始更新即可。宿主切换动作或表情后，可在暂停该角色 ticker 的期间调用 `prepare()`，将待应用状态以零时间求值并准备实际绘制。准备期间不推进动作、表情过渡或宿主眨眼时钟。`prepare()` 完成是离屏准备边界；舞台挂接、淡入及最终可见帧由宿主管理。

## 注视方向

`options.focus` 设置初始注视输入，运行中使用 `actor.setFocus({ x, y, instant })` 更新。`x/y` 限幅到 `[-1, 1]`，正值分别表示向右、向上；零值撤去注视附加量。`instant: true` 立即设置，其他情况随角色更新平滑变化。省略的分量保留当前目标值。

注视在当前动作之上附加头颈和少量上身旋转，模型的眼球控制由其参数表情适配模块提供。切换动作或表情保留注视目标。宿主领取预热实例时，应写入当前注视状态；若需首帧立即体现方向，使用 `instant: true` 后调用 `prepare()`。
